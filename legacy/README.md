# Dragon Quest Historical Source

This directory preserves the surviving custom source from Jamie Whitten's 2002-era RPG prototype.

The original project began as DirectX learning work and grew into a custom RPG and game-engine experiment. The retained files contain Jamie's game-specific application loop, state handling, rendering coordination, input, map and event scripting, hero movement, collision, UI, weather effects, debugging console, and experimental networking.

Tutorial- and sample-derived platform components have intentionally been removed from this clean historical source tree pending provenance review. Media assets, historical executables, debug artifacts, and other files whose publication rights are not established have also been excluded. Their former roles and review status are recorded under `../docs/`.

This historical source is not expected to compile in its current form. The original project metadata is preserved without modification under `project/`, and the source files have not been rewritten, reformatted, or modernized to accommodate the new directory layout or the removed dependencies.

Any modern version of the game will be reconstructed separately. The files here are a historical baseline, not a modern engine or a partially modernized port.
